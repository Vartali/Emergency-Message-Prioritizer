# Emergency Message Prioritizer

An NLP-based machine learning project that classifies emergency-related messages into four categories:

- Casualties
- Infrastructure Damage
- Rescue Request
- Not Relevant

## Problem Statement

During emergencies and disasters, a large number of messages can be generated on social media. Manually identifying which messages contain information about casualties, infrastructure damage, rescue requests, or non-humanitarian content can be difficult.

This project uses Natural Language Processing (NLP) and machine learning to automatically classify emergency-related messages into four categories.

## Dataset

This project uses the HumAID dataset, which contains real disaster-related social media messages.

For this project, four relevant categories were selected:

- `injured_or_dead_people` → Casualties
- `infrastructure_and_utility_damage` → Infrastructure Damage
- `requests_or_urgent_needs` → Rescue Request
- `not_humanitarian` → Not Relevant

The selected data was divided into training, validation, and test sets.

### Dataset Size

| Split | Samples |
|---|---:|
| Training | 17,065 |

## Methodology

The project follows these steps:

1. **Data Preparation**
   - Load the HumAID dataset.
   - Select the four target categories.
   - Separate the data into training, validation, and test sets.

2. **Text Feature Extraction**
   - TF-IDF (Term Frequency–Inverse Document Frequency) is used to convert text into numerical features.
   - Up to 10,000 features are used.
   - Both unigrams and bigrams are considered using `ngram_range=(1, 2)`.

3. **Model Training**
   - Logistic Regression is trained on the TF-IDF features.
   - `class_weight="balanced"` is used to account for differences in category sizes.

4. **Model Evaluation**
   - The model is evaluated using:
     - Accuracy
     - Precision
     - Recall
     - F1-score
     - Confusion Matrix

5. **Model Saving**
   - The trained Logistic Regression model is saved as `model.pkl`.
   - The TF-IDF vectorizer is saved as `vectorizer.pkl`.

   ## Results

The final Logistic Regression model achieved the following results on the unseen test set:

**Test Accuracy: 89.88%**

 ## Example Prediction

The trained model can also classify a new message entered by the user.

Example input:

> An accident happened on the highway and several people were injured.

Example output:

> **Predicted Category: Casualties**

The prediction is generated by transforming the new message using the saved TF-IDF vectorizer and passing the resulting features to the trained Logistic Regression model.
